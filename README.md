# Customer Segmentation using RFM Analysis

## 📊 Project Overview

This project develops an RFM (Recency, Frequency, Monetary) based customer segmentation analysis to identify different customer groups and support data-driven marketing decisions.

The project demonstrates an end-to-end analytics workflow using SQL, BigQuery, and Looker Studio.

## 🎯 Objectives

- Analyze customer purchasing behavior
- Calculate Recency, Frequency, and Monetary values
- Develop RFM-based customer segments
- Identify high-value and at-risk customers
- Compare revenue contribution across customer segments
- Build an interactive business intelligence dashboard

## 🧩 Customer Segments

The analysis classifies customers into four key segments:

- **Champions**
- **Loyal Customers**
- **Potential Loyalists**
- **At Risk**

These segments can help businesses design targeted customer retention and engagement strategies.

## 📈 Dashboard

The Looker Studio dashboard provides:

- Total number of customers
- Total revenue
- Average purchase frequency
- Average recency
- Customer segment distribution
- Revenue by customer segment
- Top customers by monetary value
- Customer value analysis

## 🔍 Key Analysis

The dashboard enables analysis of:

**Recency**  
How recently customers made a purchase.

**Frequency**  
How frequently customers purchased.

**Monetary Value**  
How much customers contributed to revenue.

The three dimensions are combined to create meaningful customer segments for marketing decision-making.

## 💡 Business Insights

The analysis can support:

- Customer retention strategies
- High-value customer identification
- Customer reactivation campaigns
- Loyalty program design
- Targeted marketing campaigns
- Revenue optimization
